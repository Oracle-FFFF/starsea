《星海余烬》更新计划
====================

- [x] 可缩放星图：银河 → 星区 → 星系 → 行星（势力范围/航道/星门/迷雾）
- [x] 54 个手工星系 + 约 260 个种子生成星系，行星由种子确定性生成
- [x] 已探索星系持久化、勘测、登陆、AI 星球档案生成
- [x] 八大势力 + 40 张原创角色卡 + 80 条原创世界书
- [x] 8 种玩家出身（Kenshi 式多身份）
- [x] 舰队编队 / 舰船购买 / 维修
- [x] 市场贸易（价格波动、货舱、燃料）
- [x] 基础 LLM 对话（OpenAI 兼容、流式、自动上下文）
- [x] 航线事件（劫掠/弦啸/打捞）与航程日志

- [x] 总故事驱动面板（星图首页）：跃迁到达/时间推进/事件弹卡/AI 叙事（本地模板兜底）
- [x] 事件与支线任务：事件卡选择、货运/勘测委托自动结算

v0.07（当前 · 知识边界与小隊版）
- [x] 修复「切到对话再切回星图，地图消失」回归（resize 双保险 + 切回自动重绘）
- [x] 星图新增「⌖ 一键定位当前位置」按钮
- [x] 对话栏重构：旁白 / 小队（同行者）/ 身边（实时）/ 通讯录（远程 2 晶）/ 知名人物（需先取得联系方式）
- [x] 知识边界：开局只知身边之人与赫赫之名，远方普通人不可见；情报页按 全部/身边·小队/知名/传闻 分类并带徽章
- [x] NPC 主动搭话：抵达新地点时，当地人物可能上前搭话（回应可得联系方式+好感）
- [x] 联系方式获取：面对面交谈自动交换 / 掮客兜售通讯录事件 / 搭话回应
- [x] Kenshi 式小队雏形：好感 ≥10 且同处一地可邀请同行，小队成员随玩家跃迁
- [x] 新游戏角色工坊：出身预设预填 + 全字段可改（名字/性别/年龄/身高/体重/发色/瞳色/脸型/长相/身体构造/身材/背景/家族/喜好/愿望/势力倾向/启动资金/行囊/五维分配 ≤30）
- [x] 设置页 API 密钥可视切换（眼睛按钮）+ 代理地址 + 系统代理（fate 同款思路）
- [x] 修复：生成星系的行星无法 AI 生成档案（服务端不认识 minor 星系，现由前端携带描述，全部星系可用）
- [x] 修复：生成星系间的自动航道无法跃迁（跃迁判定改用完整航道集，含自动航道）
- [x] 修复：流式对话挂死（SSE 缺 Connection: close）+ 内置 Node TLS 代理（部分网关按指纹拦截）+ 401 自动重试
- [x] 手工星系缺行星数据的自动补齐生成行星（每个星系均可探索）
- [x] 星球档案体系化：24 个核心星球写入本地固定大纲（planet_core.json，气候/经济/政治/文化/种族/资源 + 72 个登录区域），并合并为世界书「星球档案」分类
- [x] 边缘星球半随机结构化档案：按「条目+势力+类型+存档种子」生成，同存档不重复、不同存档独立；AI 可用时由 AI 生成结构化 JSON，失败/无 AI 回退确定性生成
- [x] 登陆过场：选择具体登录区域 → 消耗 6 小时 → 场景叙事 → 触发事件卡（向导揽客/稽查/矿工求救…）或遭遇当地 NPC
- [x] 世界书「星球档案」分类（24 条固定大纲）+ 切分类选中项自动同步
- [x] 对话面板子面板化：每个可对话对象（含星海之主/群聊）独立 tab 独立会话，tab 按 小队>身边>通讯录>知名 排序，带渐隐与对象信息条（已知范围内）
- [x] 群聊：与身边/小队的人同聊，参与者可能回应也可能不理睬；星海之主自动生成简短摘记
- [x] 存档持久化：故事驱动播报写入 state.driverFeed，聊天按 NPC/群聊分归属存储，重开存档全部恢复、不重复生成；新档与旧档完全独立
- [x] 对话面板角色档案：每个 NPC tab 内嵌完整档案（16 字段：性别年龄/种族势力/职业故乡/地位声望/外貌/特征衣着/生理/能力/装备/喜好/厌恶恐惧/习惯/性格/政治立场/目标/口头禅），一键开合
- [x] 全局联动：故事驱动中的地点变化（如「进入停泊区的酒吧」）实时同步到对话面板——旁白 tab 时间线、tab 列表与群聊在场者即时刷新；登陆点同步为当前地点
- [x] 修复：刷新页面后「你在 X 醒来」播报重复入列（driverFeed 去重 + 醒来播报每档仅一次）
