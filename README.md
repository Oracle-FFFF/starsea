# 星海余烬 · EMBERS OF THE STAR SEA

> 星历 3107 年 · 余烬纪元 —— 大崩落一百八十八年后，弦网四分五裂，诸强并起，星海如烬。你是这片余烬中的一粒星火。

一个**独立前端形态的 LLM 文字游戏 demo（v0.07）**，框架借鉴工作区 `fate` 项目（本地服务 + 存档 + LLM 代理），但世界观、UI、星图系统均为原创科幻主题。角色卡与世界书结构兼容酒馆（SillyTavern）spec v2，将来可平滑导出/扩展。

## 快速开始

- **Windows**：双击 `一键启动.bat`（自动寻找 Python、启动服务器并打开浏览器）
- **手动**：`python server.py` → 浏览器打开 http://127.0.0.1:8090

**零第三方依赖**：仅需 Python 3.7+ 标准库，无需 pip 安装任何东西。存档在 `runtime/starsea.db`（SQLite）。

## 玩法（v0.07）

1. **总故事驱动**（首页左侧）：跃迁到达、时间推进、事件与支线任务都会在此播报，并弹出行动选项；可直接向「星海之主」描述你的行动（接入 AI 后为生成式叙事，未接入时为本地模板兜底）。
2. **出身选择**：8 种身份（星港拾荒者 / 流浪佣兵 / 破落贵族 / 逃亡奴隶 / 商团见习 / 航线信使 / 流明探寻者 / 无名氏），不同起始资金、舰船、声望与特权。
3. **星图探索**（本作核心）：滚轮缩放、拖动平移，从**银河全景 → 星区 → 星系 → 行星**逐级深入；势力范围以**发光云团**渲染（随缩放溶解），银河旋臂、虚线航道、金色星门（Aurora Gate 等）；「航」「域」一键开关可对比航道/势力显示效果；未勘测星系可付费勘测（持久化保存）。
4. **事件与支线**：到达新地点概率触发事件卡（漂流货箱 / 求救信号 / 偷渡客 / 灰潮巡哨…），货运与勘测委托可接取并自动结算。
5. **社交判定**：对话需过距离与身份门槛——同星系实时对话、远方只能通讯（2 晶/次）、地位悬殊可能被拒；对话增进好感；40 位角色分「公开 / 传闻 / 隐藏」三级情报，隐藏角色由星海中的行迹触发解锁。
6. **角色词条**：每位角色含外貌 / 性格 / 生理 / 能力 / 政治派系 / 声望地位 / 好感 / 关系 / 秘闻 / 口头禅，以及横跨五百年的「命运线」（至 3607 年）；银河大事件时间线随年份推进，无论玩家是否参与都会发生。
7. **贸易与舰队**：十二种商品随星系经济与时间波动；12 种舰船编队 / 维修 / 购买；AI 星球档案生成。
8. **世界书**：104 条设定（80 条原创历史/派系/文化条目 + 24 颗核心行星的「星球档案」固定大纲）。
9. **子面板对话**：旁白（星海之主）／群聊／每位可接触角色各占独立 tab，会话互不串线、重开存档完整恢复；旁白 tab 与星图页故事驱动是同一时间线，地点变化（如「进入停泊区的酒吧」）实时同步；每个 NPC tab 内嵌 16 字段完整档案（外貌/能力/装备/性格/政治立场/目标…）。
10. **群聊**：与身边（当前星系）的人同聊，有人回应也有人不理睬，星海之主自动摘记。
11. **角色工坊**：新游戏可自选出身预设并修改全部字段（外貌/五维/行囊/资金/势力倾向）。
12. **星球档案与登陆**：24 颗核心行星固定档案 + 边缘行星按存档种子半随机生成；登陆选择具体区域，有过场叙事与当地事件/NPC 遭遇。

## 命名规范

星系为西式硬科幻命名（Lumina、Coronis、Tideport、Vulcan's Hearth、Gliese 731…）；势力与人物采用「中文译名（外文原名）」双写，如 **奥瑞利安合众国（Aurelian Commonwealth）**、**艾琳·韦特（Aileen Vett）**。

## AI 接入

任意支持 `/chat/completions` 的 OpenAI 兼容服务均可（OpenAI / DeepSeek / GLM / Kimi / 本地 Ollama / hiapi.online 等）：
**设置 → AI 连接** 填写接口地址（到 `/v1` 一级）、密钥与模型名，点「测试连接」。

- **网络受限**（本机需代理才能访问外网 API）：可勾选「使用系统代理」，或直接填写**代理地址**（如 `http://127.0.0.1:7897`，Clash/Mihomo 的混合端口）。
- **401 / Invalid token**：表示网关不承认这把密钥（无效、过期、或与接口地址不匹配）——请从提供商后台**重新复制**密钥；注意同一家提供商可能有新旧多把密钥，别拿错了。
- **403 quota / 余额不足**：密钥有效但账户余额不够支付本次请求——请到提供商后台充值；测试连接只花几分钱所以能通过，正式对话金额更大就会失败。
- **「测试连接成功但对话失败/极慢」**：检查模型名是否与后台一致，并调低「最大输出 tokens」（部分网关生成很慢，建议 800-1200）。
- **「对话正常但 AI 星球档案提示未接入」**：说明 AI 其实没有保存——左侧故事驱动在未配置时会静默使用本地模板（会标注「本地」）。现在「测试连接」会**自动保存**配置，点完测试即可；或手动点「保存配置」。
- **hi api（hiapi.online）实测**：模型名用 `gemini-3.1-pro-preview` 或 `gemini-3-pro-preview` 均可；密钥需与后台完全一致（曾因旧密钥未在网关注册导致 401，另一次因账户余额不足导致 403）。

对话时会自动组装：叙事者主卡 + 所选 NPC 角色卡 + 匹配关键词的世界书条目（含常驻条目）+ 玩家身份/舰船/声望 + 当前星系/行星档案。
