# 星海余烬 · EMBERS OF THE STAR SEA

> 星历 3107 年 · 余烬纪元 —— 大崩落一百八十八年后，弦网四分五裂，诸强并起，星海如烬。你是这片余烬中的一粒星火。

一个**独立前端形态的 LLM 文字游戏 demo（v0.05）**，框架借鉴工作区 `fate` 项目（本地服务 + 存档 + LLM 代理），但世界观、UI、星图系统均为原创科幻主题。角色卡与世界书结构兼容酒馆（SillyTavern）spec v2，将来可平滑导出/扩展。

## 快速开始

- **Windows**：双击 `一键启动.bat`（自动寻找 Python、启动服务器并打开浏览器）
- **手动**：`python server.py` → 浏览器打开 http://127.0.0.1:8090

**零第三方依赖**：仅需 Python 3.7+ 标准库，无需 pip 安装任何东西。存档在 `runtime/starsea.db`（SQLite）。

## 玩法（v0.05 已可玩）

1. **出身选择**：8 种身份（星港拾荒者 / 流浪佣兵 / 破落贵族 / 逃亡奴隶 / 商团见习 / 航线信使 / 曦光探寻者 / 无名氏），不同起始资金、舰船、声望与特权。
2. **星图探索**（本作核心）：滚轮缩放、拖动平移，从**银河全景 → 星区 → 星系 → 行星**逐级深入；势力范围一目了然；未勘测星系可付费勘测（已探索星系持久化保存）；跃迁消耗渊髓燃料，抵达时触发航线事件。
3. **贸易**：十二种商品，价格随星系经济类型、危险度与时间波动，低买高卖赚取差价；可在市场补充燃料。
4. **舰队**：编队管理、切换座舰、维修；在船坞星系购买从拾荒小艇到巡洋舰的 12 种舰船。
5. **角色与对话**：40 位原创角色完整档案（外貌/性格/背景/目标/关系/秘闻）；接入任意 OpenAI 兼容接口后即可与旁白或任意 NPC 对话（流式输出，自动组装角色卡 + 世界书 + 当前位置上下文）。
6. **AI 星球档案**：勘测后的行星可一键生成 AI 叙事档案（未配置 AI 时回退为自动勘测档案）。
7. **世界书**：80 条原创设定（历史 / 派系 / 政治 / 文化 / 经济 / 科技 / 地理 / 物种 / 危险）。

## AI 接入

任意支持 `/chat/completions` 的 OpenAI 兼容服务均可（OpenAI / DeepSeek / GLM / Kimi / 本地 Ollama 等）：
**设置 → AI 连接** 填写接口地址（到 `/v1` 一级）、密钥与模型名，点「测试连接」。

对话时会自动组装：叙事者主卡 + 所选 NPC 角色卡 + 匹配关键词的世界书条目（含常驻条目）+ 玩家身份/舰船/声望 + 当前星系/行星档案。
